# `data/`

This folder ships the **survey schema** (column → question text) only. The
two larger files are not redistributed in this repo:

| File | Size | Where to get it |
|---|---|---|
| `survey_results_public.csv` | 135 MB | <https://survey.stackoverflow.co/datasets/stack-overflow-developer-survey-2025.zip> |
| `2025_Developer_Survey_Tool.pdf` | 1 MB | same zip as above |

```bash
cd data/
wget https://survey.stackoverflow.co/datasets/stack-overflow-developer-survey-2025.zip
unzip stack-overflow-developer-survey-2025.zip
```

The 2025 Stack Overflow Developer Survey is published under the
**Open Database License (ODbL)**.
